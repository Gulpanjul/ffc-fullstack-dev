## How Can You Use File Management Applications on Your Computer?

### Questions

</div>

**1. What is the default file management application on a Windows computer?**

- [ ] Finder  
- [ ] Smart Folders  
- [x] File Explorer  
- [ ] Spotlight  

**2. How can you pin a folder in File Explorer on a Windows computer?**

- [x] Right-click the folder and select "Pin to Start".  
- [ ] Press "Ctrl + Pin".  
- [ ] There is no option to pin a folder.  
- [ ] Drag the folder to the taskbar.  

**3. On a Mac, how do you access the Finder?**

- [x] Click on the Finder icon in the Dock.  
- [ ] Press "Command + Find".  
- [ ] Go to the Start menu.  
- [ ] Open the Spotlight search.
