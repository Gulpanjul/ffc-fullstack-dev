### Questions

**1. When is it most appropriate to use inline CSS?**

- [ ] For styling all paragraphs in a document.  
- [x] For overriding styles quickly on a single element.  
- [ ] For styling an entire website.  
- [ ] For separating concerns in large projects.  

**2. Which type of CSS is best suited for applying styles to a single webpage only?**

- [ ] Inline CSS.  
- [ ] External CSS.  
- [x] Internal CSS.  
- [ ] Universal CSS.  

**3. Why is external CSS preferred in larger projects?**

- [ ] It allows for quick, one-time style changes.  
- [ ] It applies styles to only a specific element.  
- [x] It promotes separation of concerns and reusability across multiple pages.  
- [ ] It makes the HTML more complicated.
