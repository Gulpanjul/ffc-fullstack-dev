## How Does Inline-Block Work, and How Does It Differ from Inline and Block Elements?

### Questions

</div>

**1. What is the key characteristic of an inline-block element that distinguishes it from an inline element?**

- [ ] Inline-block elements cannot be nested inside block elements.  
- [ ] Inline-block elements automatically span the full width of their container.  
- [x] Inline-block elements allow setting of height and width, unlike inline elements.  
- [ ] Inline-block elements always break onto a new line.  

**2. Which scenario is best suited for using inline-block elements over inline or block elements?**

- [ ] When you need an element to take up the entire width of its parent container.  
- [x] When you want an element to remain inline but need to adjust its size.  
- [ ] When you need an element to always start on a new line.  
- [ ] When you don't want an element to be affected by padding and margins.  

**3. In what situation would an element with `display: inline-block;` behave differently than one with `display: block;`?**

- [ ] When you need the element to take up the entire width of the container.  
- [x] When you want the element to flow alongside text and other inline elements.  
- [ ] When you need the element to start on a new line automatically.  
- [ ] When you don't want the element to have any height or width properties.
