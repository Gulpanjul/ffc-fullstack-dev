**3. What color will the text be in the following example?**

```html
<head>
  <style>
    p {
      color: red;
    }
  </style>
</head>
<body>
  <p style="color: blue;">This text</p>
</body>
```

- [x] blue
- [ ] red
- [ ] yellow
- [ ] green
