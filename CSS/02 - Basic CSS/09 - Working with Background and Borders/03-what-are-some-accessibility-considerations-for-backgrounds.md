## What Are Some Accessibility Considerations for Backgrounds?

### Questions

</div>

**1. Why is it important to maintain sufficient contrast between text and background?**

- [ ] To make the page look more colorful.  
- [x] To make the text more readable for all users.  
- [ ] To reduce loading times on the webpage.  
- [ ] To highlight text in different ways.  

**2. Which of the following should be avoided when placing text over a background?**

- [ ] Applying a high-contrast background.  
- [x] Using a busy or complex background without any overlay.  
- [ ] Using white text on a black background.  
- [ ] Using a solid background color behind text.  

**3. What is the issue with using color as the only indicator of information, such as showing an error message in red?**

- [ ] It makes the website look less colorful.  
- [ ] It doesn't affect users with visual impairments.  
- [x] It can be problematic for users with color blindness.  
- [ ] It requires more CSS code.
