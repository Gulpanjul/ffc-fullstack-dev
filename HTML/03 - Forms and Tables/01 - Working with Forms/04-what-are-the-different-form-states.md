## What Are the Different Form States, and Why Are They Important?

### Questions

</div>

1. Which attribute is used to disable an input?

   - [ ] readonly  
   - [ ] required  
   - [ ] checked  
   - [x] disabled  

2. Which attribute is used to mark an input read only?

   - [ ] checked  
   - [x] readonly  
   - [ ] size  
   - [ ] capture  

3. When does the focus state occur?

   - [ ] When an input field is disabled and cannot be interacted with.  
   - [ ] When an input field is validated and shows an error message.  
   - [x] When the user clicks on an input or selects it using the tab key to focus it.  
   - [ ] When an input field has been pre-filled with default values by the browser.
