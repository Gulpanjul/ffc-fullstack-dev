## What Are HTML Tables Used For, and What Should They Not Be Used For?

### Questions

</div>

1. In an HTML table, which elements are contained within a `tr` element?

   - [ ] thead and tfoot.
   - [x] td and th.
   - [ ] table and tbody.
   - [ ] div and span.

2. Which of the following are the main sections of an HTML table?

   - [ ] table, div, and span.
   - [ ] header, section, and footer.
   - [x] thead, tbody, and tfoot.
   - [ ] article, aside, and nav.

3. What is the main recommended use of HTML tables today?

   - [ ] Creating page layouts.
   - [x] Displaying tabular data.
   - [ ] Styling with CSS.
   - [ ] Embedding images.
